\subsection{\texttt{solve\_q1.py} — 问题一:半经验关联式标定与机理分析}

\begin{enumerate}[label=(\arabic*)]
    \item 压降幂律关联式 $\ln\Delta P^*=\ln C+a\ln\beta+b\ln(1-\alpha)+c\ln n$ 的最小二乘标定
    \item 热阻二次结构关联式 $R_{th}^*=R_0+c_1(\alpha-\alpha^*)^2+c_2\beta+c_3 n+c_4\alpha n$ 的非线性拟合
    \item 基于 GPR 代理模型的控制变量影响幅度定量表
    \item $\alpha^*$ 拐点的 GPR 交叉验证(逐点扫描求 $\bar{R}_{th}^*$ 的 argmin)
    \item 机理关联式与数据一致性定量检验(MAPE, $R^2$)
\end{enumerate}

    caption={solve\_q1.py},

\subsection{\texttt{solve\_q2.py} — 问题二:GPR 代理模型构建}

以 $\alpha,\beta,n$ 为输入、$R_{th}^*,\Delta P^*,\Delta T^*$ 为输出,
采用 Constant$\times$RBF(各向异性)+White 复合核构建高斯过程回归代理模型。
按 8:2 留出法划分训练/测试集,对每个输出维度独立训练(MISO 架构),
并提取 MLE 最优核超参数 $\theta^*=[\sigma_f,l_1,l_2,l_3,\sigma_n]$。
训练完成的模型保存为 \texttt{gpr.pkl},供后续问题三--五复用。

\lstinputlisting[
    caption={solve\_q2.py},
    label={lst:solve_q2},
    firstnumber=auto,
]{../code/src/solve_q2.py}

\subsection{\texttt{solve\_q3.py} — 问题三:混合多目标优化与决策}

三段式混合策略:
\begin{enumerate}[label=(\arabic*)]
    \item 混合变量 NSGA-II (mode 变量处理 $\alpha=0\Leftrightarrow n=0$ 的耦合约束),多种子拼接 Pareto 前沿
    \item 在全体合法 $(\beta,n)$ 离散组合上穷举,L-BFGS-B 精修 $\alpha$
    \item 均等权重理想点法选出综合最优方案 $\mathbf{X}^*$
\end{enumerate}

\lstinputlisting[
    caption={solve\_q3.py},
    label={lst:solve_q3},
    firstnumber=auto,

\subsection{\texttt{solve\_q4.py} — 问题四:鲁棒优化}

\begin{enumerate}[label=(\arabic*)]
    \item 三类典型应用场景(高性能计算、便携低功耗、高可靠工业)与权重单纯形网格的扫描
    \item 敏感性矩阵 $\mathbf{S}_{ij}=\partial x_i/\partial w_j$ (中心差分)
    \item 基于 Minimax Regret 准则的鲁棒方案搜索
    \item 跨场景稳定性评估(权重空间变异系数 CV)
\end{enumerate}
复用 \texttt{solve\_q3} 的 \texttt{global\_best} 函数作为加权最优求解器。

\subsection{\texttt{solve\_q5.py} — 问题五:敏感性分析与不确定性传播}

结构参数层(GPR 直接支撑):
\begin{itemize}
    \item Sobol 全局敏感性指数(一阶 $S_i$ 与总效应 $S_{Ti}$, $N=1024$)
    \item 局部归一化敏感性系数 $S_{ij}^{local}$ (中心差分)
    \item LHS 蒙特卡洛不确定性传播($N=8000$, $\pm5\%$ 扰动)
\end{itemize}
工况参数层(机理标度近似):基于无量纲传热/流动标度关系的一阶线性化估计。
验证闭环:对比综合最优方案 $\mathbf{X}^*$ 与鲁棒方案的变异系数和失效概率。
