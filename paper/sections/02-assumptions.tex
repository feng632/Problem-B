\section{模型假设}

\begin{enumerate}
  \item 冷却介质(去离子水)为不可压缩、稳态流动,物性参数按平均温度取值;
  \item 忽略黏性耗散与压缩功,流体能量方程中不计黏性产热项
        (式~\ref{eq:energy-fluid} 不含耗散项);
  \item 流动状态按附件数据中的雷诺数判定为层流或湍流(本文问题一按层流建模);
  \item 忽略辐射换热,换热仅由强制对流主导;
  \item 芯片热源视为均匀体热源,强度为 $5\times10^9$~W/m$^3$,忽略边缘效应,
        体热源仅作用于芯片热源区域(见式~\ref{eq:energy-solid});
  \item 忽略芯片、衬底与冷却液之间的界面接触热阻,认为各界面传热连续;
  \item 问题一机理分析中,同一歧管单元内各通道间的微观流量分配差异忽略不计,
        流量分配均匀性的宏观效应仅通过歧管深高比 $\beta$ 等结构参数刻画;
  \item 结构参数与工况仅在附件给定的设计空间(样本支撑范围)内取值,代理
        模型在该范围内视为具有足够精度、可用于替代仿真评估,超出该范围的
        外推预测不可靠。
\end{enumerate}
