**dP关联式**(幂律,对数线性最小二乘,排除n=0的4个无针肋样本——幂律
结构里ln(n)在n=0处无定义,且"逐排叠加"机理本来就不适用于无针肋情形):
```
dP* = 0.2404 * beta^-0.9819 * (1-alpha)^-1.2432 * n^0.1681

```
beta指数为负,和"beta增大dP减小"的数据规律(见1.2表)一致。

**Rth关联式**(非线性最小二乘,全部84样本):基础式(仅R0/c1/c2/c3四项)

```
Rth* = 0.7107 + 0.5958*(alpha-0.1399)^2 + 0.0108*beta + 0.0017*n - 0.0176*alpha*n
R2=0.7486  MAPE=0.59%  (全部84个样本)
```
R2仍不到checklist期望的0.9,但MAPE本来就很低(<0.6%)——Rth数值量程本身
很窄(0.72~0.77),R2对窄量程数据不友好,不代表拟合质量差,只是这个指标
在这种数据形态下不够敏感。这个R2<0.9的情况按checklist要求记录在这里,
留给建模手判断要不要进一步改结构(比如再加beta*n交互项试试),这次没有
继续加项,时间上先保证覆盖完整链路。

GPR(R2>0.999,更可信)直接对alpha扫描求Rth均值的argmin做交叉验证:
```
alpha*(GPR argmin) = 0.235,对应Rth均值=0.7370
```
0.235和论文预期的"0.2附近"吻合,写论文时α*应该引用这个GPR交叉验证值,
不要用半经验式里被交互项污染的0.14。

## Q4

5.4: 权重敏感性 + minimax regret 鲁棒设计，全部在 GPR 代理模型上做，代码
solve_q4.py，复用 solve_q3.py 的 predict/gpr_value_range/refine_at_fixed_x2x3。

关键简化：给定权重后 D_W(X) 是单目标函数，不需要 NSGA-II——x2(4档)x3(11档)
穷举=44组合，每组合对x1做多起点L-BFGS-B（比GA稳，也不会有Q3那种"不同
种子掉进不同盆地"的问题）。

**(1)(2) 权重扫描**：3个论文给定场景 + 单纯形网格(n=6, 28点，重心坐标
w=(i/n,j/n,(n-i-j)/n)天然满足sum=1)。3个典型场景结果：
```
高性能计算(0.6,0.2,0.2):    x1=0.2220 x2=4.50 x3=5  D=0.181455
便携/低功耗设备(0.2,0.6,0.2): x1=0.0000 x2=4.00 x3=4  D=0.164484
高可靠工业器件(0.2,0.2,0.6):  x1=0.0000 x2=3.50 x3=4  D=0.137526
```

**(3) 敏感性矩阵**：中心差分，但直接对某个w_j加h会破坏sum(w)=1约束，
用的处理是"扰动方向 = e_j - (1/3)·1"（即扣分量的h/2均摊给另外两个权重），
天然保持在单纯形内，靠近边界时自动缩小步长h。这是我们对论文式(17)扰动
方向的工程化解释，论文没明确写怎么处理simplex约束，写论文时这段要说明。

结果验证了预期的"跳变"现象：在"便携/低功耗设备"场景附近，敏感性矩阵
炸出±5的异常大值——查了具体数值，发现w±0.05范围内最优解在
(x2=4.0,x1≈0)和(x2=4.5,x1≈0.22)两个解之间来回切换，这两个解的D值
非常接近，权重稍微一动全局最优就换边，是真实的Pareto拐点跳变，不是bug。
高性能计算/高可靠工业器件两个场景处敏感性矩阵平稳（没撞到跳变点）。

**minimax regret 鲁棒方案**：候选池=Q3的Pareto前沿(q3_result.pkl的
X_front, 2000点，多种子NSGA-II结果)，在31个权重采样点上评估每个候选的
最大后悔值：
```
X_robust: x1=0.2025 x2=4.50 x3=5
max_regret = 0.190396
```

结果存 q4_result.pkl。
