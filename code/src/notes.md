## Q3

5.3: NSGA-II(pymoo 0.6.2 mixed-variable)+ 理想点法(w1=w2=w3=1/3)+ 整数邻域
L-BFGS-B 精修。x3(排数)本来就按整数处理，x1/x2 连续。

单次 NSGA-II（pop=200, n_gen=200~300）不收敛：前沿存在两个局部盆地，
不同随机种子会落进不同盆地：
- 盆地A：x1≈0（下边界），D≈0.1748~0.1763（视归一化基准而定）
- 盆地B：x1≈0.22，x2=4.5（上边界），D≈0.1754~0.1756，比盆地A更优

改成多种子（10个）合并前沿再选之后，稳定收敛到盆地B：
```
x1(alpha)=0.2175  x2(beta)=4.5000  x3(n)=4
D=0.175323
预测 Rth=0.741287 dP=0.084562 dT=0.771908
```

归一化基准 gpr_value_range() 从随机采样40点改成规则网格(25x25x11)，更稳。

**边界问题排查**：查了 data.xlsx，beta 实际只有 {3.0, 3.5, 4.0, 4.5} 四档
离散取值（各21个样本），4.5 是数据集真实采到的上界，不是GPR外推——
所以边界解不是模型伪影，是有数据支撑的。

但这揭示了建模上的不一致：beta 在原始数据里是离散变量，04-models.tex 里
式(6)却把它写成连续区间约束 `3.00<=x2<=4.50`，NSGA-II/L-BFGS-B 都在按连续
变量处理它，x2=4.5000 只是精修后恰好落在采样点上。

下一步：把 x2 也改成离散变量（{3.0,3.5,4.0,4.5}四档，和x3的整数处理方式
类似），重新跑一遍看结果和分析结论是否变化。

**改成离散x2后的结果**：pymoo Choice变量处理x2(4档)，NSGA-II三变量都按
真实类型处理（x1连续、x2离散4档、x3整数）。精修阶段相应改成：x2遍历4档
+ x3邻域±1网格搜索，每个(x2,x3)组合只对x1做L-BFGS-B（1维）。

结果与连续处理版本基本一致，验证了边界解是稳健的，不是连续松弛的伪影：
```
x1(alpha)=0.2175  x2(beta)=4.5  x3(n)=4
D=0.175072
预测 Rth=0.741285 dP=0.084567 dT=0.771905
```
beta=4.5仍卡边界，两版本(连续/离散)数值几乎相同(D差在第4位小数)，
说明这个优化问题里beta本来就该往上界走，离散化只是让约束表述更符合
物理实际，没有改变结论。

论文里式(6)的连续区间约束`3.00<=x2<=4.50`可能需要改成离散集合约束，
04-models.tex待同步更新。

## Q4

5.4: 权重敏感性 + minimax regret 鲁棒设计，全部在 GPR 代理模型上做，代码
solve_q4.py，复用 solve_q3.py 的 predict/gpr_value_range/refine_at_fixed_x2x3。

关键简化：给定权重后 D_W(X) 是单目标函数，不需要 NSGA-II——x2(4档)x3(11档)
穷举=44组合，每组合对x1做多起点L-BFGS-B（比GA稳，也不会有Q3那种"不同
种子掉进不同盆地"的问题）。

**(1)(2) 权重扫描**：3个论文给定场景 + 单纯形网格(n=6, 28点，重心坐标
w=(i/n,j/n,(n-i-j)/n)天然满足sum=1)。3个典型场景结果：
```
高性能计算(0.6,0.2,0.2):    x1=0.2220 x2=4.50 x3=5  D=0.181455
便携/低功耗设备(0.2,0.6,0.2): x1=0.0000 x2=4.00 x3=4  D=0.164484
高可靠工业器件(0.2,0.2,0.6):  x1=0.0000 x2=3.50 x3=4  D=0.137526
```

**(3) 敏感性矩阵**：中心差分，但直接对某个w_j加h会破坏sum(w)=1约束，
用的处理是"扰动方向 = e_j - (1/3)·1"（即扣分量的h/2均摊给另外两个权重），
天然保持在单纯形内，靠近边界时自动缩小步长h。这是我们对论文式(17)扰动
方向的工程化解释，论文没明确写怎么处理simplex约束，写论文时这段要说明。

结果验证了预期的"跳变"现象：在"便携/低功耗设备"场景附近，敏感性矩阵
炸出±5的异常大值——查了具体数值，发现w±0.05范围内最优解在
(x2=4.0,x1≈0)和(x2=4.5,x1≈0.22)两个解之间来回切换，这两个解的D值
非常接近，权重稍微一动全局最优就换边，是真实的Pareto拐点跳变，不是bug。
高性能计算/高可靠工业器件两个场景处敏感性矩阵平稳（没撞到跳变点）。

**minimax regret 鲁棒方案**：候选池=Q3的Pareto前沿(q3_result.pkl的
X_front, 2000点，多种子NSGA-II结果)，在31个权重采样点上评估每个候选的
最大后悔值：
```
X_robust: x1=0.2025 x2=4.50 x3=5
max_regret = 0.190396
```

结果存 q4_result.pkl。
